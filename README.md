# Визуализации по математике

Интерактивные материалы к курсу алгебры (ОП «Математика», I семестр).
Каждый файл — самостоятельная HTML-страница: открывается двойным кликом,
ничего устанавливать не нужно, интернет нужен только для подгрузки шрифтов.

## Что внутри

| Файл | Тема | Билеты |
|---|---|---|
| `index.html` | Главная страница со списком всех визуализаций | — |
| `pages/complex-rotation.html` | Повороты на комплексной плоскости, формула Муавра, корни из единицы | 37–39 |
| `pages/polynomials-map.html` | Карта зависимостей утверждений в алгебре многочленов | 55–66 |
| `pages/course-map.html` | Магистрали курса: сквозные инструменты и их охват | 1–72 |

## Публикация через GitHub Pages

1. Залить содержимое репозитория в ветку `main`.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу
   `https://<ник>.github.io/<репозиторий>/`.

Главная страница — `index.html` в корне, поэтому отдельной настройки не требуется.

## Ссылки на конспекты

Страница `course-map.html` умеет открывать конспект на нужной странице
(`файл.pdf#page=N` — работает в Chrome, Firefox и Safari).

Чтобы ссылки заработали, положите PDF-конспекты в папку `konspekty/` в корне
репозитория под такими именами:

```
konspekty/линал.pdf              билеты 1–17
konspekty/группы.pdf             билеты 18–32
konspekty/кольца_33-42.pdf       билеты 33–42
konspekty/делимость_43-54.pdf    билеты 43–54
konspekty/многочлены_55-66.pdf   билеты 55–66
konspekty/теорчисел_67-72.pdf    билеты 67–72
```

Имена файлов и номера страниц настраиваются в объекте `NOTES` в начале скрипта
`course-map.html`. Если выкладывать конспекты не хочется, поставьте
`base: ""` — ссылки просто перестанут отображаться, всё остальное продолжит работать.

## Как добавить новую визуализацию

1. Положить HTML-файл в папку `pages/`.
2. В начале `index.html` найти массив `ITEMS` и дописать один объект:

```js
{
  file:  "pages/имя-файла.html",  // null, если материал ещё не готов
  tag:   "Билеты 40–42",          // метка над заголовком карточки
  color: "a",                     // "a" синий, "b" охра, "c" бирюза
  title: "Название",
  desc:  "Одно-два предложения о том, что внутри.",
  date:  "2026-09-01"
}
```

Карточка, счётчик материалов и дата обновления на главной пересчитаются сами.

## Технические заметки

- Каждая страница самодостаточна: весь CSS и JS внутри файла, внешних зависимостей нет.
- Шрифты (Spectral, IBM Plex Sans, IBM Plex Mono) грузятся с Google Fonts;
  без интернета страницы работают, просто подставляются системные шрифты.
- Светлая и тёмная темы переключаются автоматически по настройке системы.
- Графика — Canvas и SVG, рисуется в браузере, картинок в репозитории нет.
